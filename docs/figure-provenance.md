# Profile figure provenance

The six evidence visuals in this profile are local copies of figures in the organized research projects and area hub. They are previews, not replacements for complete methods, underlying source records, or article figures. Measurement-derived plots, computational output, and explanatory diagrams are identified separately.

| Profile asset | Source material | Processing and interpretation |
| --- | --- | --- |
| `assets/evidence/acid-exposure-rf-response.svg` | `VNA/Horn Antenna/AcidAttack.csv` in the supplied archive | Generated by the contactless-acid project `src/analyze.py`. Six archived response series were plotted against frequency. The CSV does not independently document all specimen preparation, instrument calibration, or response-unit metadata; consult the original notebooks and published paper before making quantitative physical comparisons. |
| `assets/evidence/resonator-vs-void-s21.svg` | `VNA/RESONATOR/Experimental/S21Resonator.prn` and `S21Void.prn` in the supplied archive | Generated by the antenna-resonator project `src/analyze.py`. Experimental S21 magnitude traces were compared in dB. This is not a newly acquired measurement or a simulation prediction. |
| `assets/evidence/matlab-occupancy-grid.png` | `DEEP MOTION/Robotics/Plano.jpg` and `Grid1.m` in the motion-planning project | Generated by running the supplied MATLAB script on its adjacent map image. The image grid has no independently calibrated physical distance; it is not evidence of robot navigation performance. |
| `assets/evidence/turtle-system.svg` | Robotic-turtle presentation, CAD, calculations, and demonstration material in the organized project | Original explanatory system diagram from the robotic-turtle project. It describes the concept/prototype architecture, not measured performance. |
| `assets/evidence/industrial-delivery-flow.svg` | Industrial-engineering area hub and the supplied portfolio PDF, especially project records on pages 19–21 | Original explanatory workflow diagram copied from the industrial-delivery hub. Project outcomes mentioned in the README are portfolio-reported rather than independently remeasured here. |
| `assets/evidence/fuzzy-evaluation-architecture.svg` | Hybrid-education FIS models and methodology in the organized project | Original explanatory architecture diagram copied from the hybrid-education project. It illustrates model structure and is not an outcome plot. |

The profile's `assets/research-map.svg` and `assets/profile-header.svg` are original explanatory graphics, not experimental data. Inline publication links in the README point to studies associated with the broader research programme; the re-plotted profile figures should not be mistaken for figures reproduced from those papers.
